# Dinaminė duomenų anketa

Naudotojo sąsajos kūrimo praktinė užduotis Nr. 3. Darbo tikslas – naudojant HTML, CSS ir JavaScript sukurti kliento anketą, kurios laukai keičiasi pagal naudotojo atsakymus.

Anketą sudaro keturios dalys: asmens ir šeimos duomenys, kontaktai, išsilavinimas ir profesinė padėtis. JavaScript per DOM parodo tik aktualius laukus ir pagal asmens kodą automatiškai užpildo lytį, gimimo datą bei metus. Eigos juosta rodo, kiek dalių užpildyta, o išdėstymas prisitaiko prie siauro ekrano. Pildant atsakymai laikomi viename JavaScript objekte naršyklės atmintyje. Užbaigus anketą jie išvalomi, o mygtukas „Pildyti iš naujo“ atidaro tuščią anketą.

## Paleidimas

Atidarykite `index.html` naršyklėje. Serverio ir papildomų paketų nereikia.

- `index.html` – puslapio struktūra.
- `styles.css` – išvaizda ir prisitaikymas prie ekrano pločio.
- `anketa.js` – laukų kūrimas, įvesties tikrinimas ir pildymo eiga.
